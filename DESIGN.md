# DESIGN SYSTEM — ArchitectBeauty (Airbnb + Notion Hybrid)

## Источники
- **Основной референс**: `./airbnb/DESIGN.md` — тёплый marketplace-стиль, карточки, фотографии, coral-акцент.
- **Второстепенный референс**: `./notion/DESIGN.md` — минимализм, дашборды, типографика, мягкие поверхности.

**Правило для AI:** 
Всегда в первую очередь следуй Airbnb-стилю для клиентской части (поиск, карточки, профили мастеров). 
Для внутренних кабинетов и дашбордов мастеров — Notion-стиль. 
При противоречиях — отдавай приоритет Airbnb.

---

## Гибридный Design System (ArchitectBeauty)

## 1. Общая философия
Создаём тёплый, доверительный и профессиональный интерфейс для строительного маркетплейса (поиск мастеров по ремонту квартир и домов).

- Клиентская часть → **Airbnb** (эмоционально, визуально насыщенно, большие фото)
- Кабинет мастера + дашборды → **Notion** (структурировано, минималистично, удобно)

## 2. Цветовая палитра (Airbnb dominant)
- **Primary**: `#FF5A5F` (Coral)
- **Primary Hover**: `#E04A4E`
- **Accent / Success**: `#00A699` (Teal)
- **Background**: `#FAF9F6` (тёплый Notion)
- **Surface**: `#FFFFFF`
- **Text Primary**: `#111111`
- **Text Secondary**: `#555555`

## 3. Типографика (Notion influence)
- Основной шрифт: **Inter** / system-ui
- Заголовки: мягкий serif-подобный вес (как в Notion)
- Отличная иерархия и читаемость

## 4. UI Правила
- Border Radius: 12–16px
- Shadows: мягкие Notion-style
- Карточки: большие, с акцентом на фотографии (Airbnb)
- "До / После" — ключевой визуальный элемент

## 5. Важные компоненты (под наш сервис)
- Карточки мастеров и заказов с большими фото работ
- Галереи портфолио с переключателем "До / После"
- Фильтры (район, вид ремонта, бюджет, сроки)
- Статусы заказов и чат
- Дашборд мастера в стиле Notion
