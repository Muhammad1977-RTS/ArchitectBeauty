# project brief — раунд 1

## обзор
**название продукта:** ArchitectBeauty

**суть продукта:** это маркетплейс который соединяет мастеров-строителей, заказчиков-клиентов, которые ищут мастеров для ремонта своих квартир, домов, грузоперевозчиков для доставки стройматериалов, грузов и строительные магазины, которые предлагают свои товары, стройматериалы, услуги, чтобы мастера, клиенты могли тут же заказать стройматериал и отвезти заказчику

**целевая аудитория:**

> Это приложение для: 
> Во-первых, клиента, которому нужен ремонт квартиры, дома. И он ищет его в приложении без посредника.
>  во-вторых для мастеров которые ищут тут заказы и работу, чтобы выполнить ремонт.
>  в-третьих  Для перевозчиков грузов, которые имеют машины. Ищут клиентов для перевозки грузов.
>  в четвёртых для строительных магазинов, чтобы они размещали свои услуги, товары, стройматериалы клиентам, заказчикам и мастерам, рабочим.

**география запуска:** Пока Чеченская республика, с возможностью добавлять регионы России

## роли пользователей
**метод авторизации:** email + пароль

**поля профиля клиента:**

> имя
> телефон
> город/район
> требуемый вид работ, услуг

**поля профиля мастера:**

> имя
> телефон
> специализация (плитка, сантехника, электрика...)

**верификация мастера:** нет — зарегистрировался и сразу работает

## заявки
**виды работ MVP:**
- покраска стен потолка, сантехника, электрика, напольные покрытия (ламинат, паркет), потолки (натяжные, гипсокартон), общестроительные работы (под ключ), укладка плитки, штукатурка, шпаклёвка стен потолка, кладка кирпича, стяжка, сварочные работы

**поля заявки:**

> имя
> телефон
> специализация (плитка, сантехника, электрика...)
> опыт (лет)

**видимость заявок для мастеров:** все мастера видят все заявки

**схема статусов заявки:** простая: новая → мастер выбран → завершена

## отклики и выбор мастера
**поля отклика мастера:**

> реши сам

**лимит откликов:** без ограничений

**уведомления в MVP:** email (через Supabase / Resend) ✅ сделано

## расчёт стоимости
**формула расчёта стоимости:** площадь × ставка мастера за м²

**дифференциация ставок по типу работ:** мастер задаёт ставку отдельно для каждого типа работ

**онлайн-оплата в MVP:** только договорённость — оплата напрямую между людьми

## вне MVP
**критерий готовности MVP:** первая реальная сделка между клиентом и мастером через приложение

## открытые вопросы
**открытые вопросы:**

> ничего

**дедлайн запуска:** без определённой даты

## статус реализации

### ✅ сделано

**Авторизация и онбординг**
- Регистрация / вход по email + пароль
- Онбординг в 3 шага с навигацией назад
- Раздельные роли: клиент / мастер

**Клиент**
- Создание заявки (вид работы, площадь/количество единиц, адрес, описание, фото до 5 шт.)
- Список своих заявок со статусами
- Просмотр откликов мастеров (аккордеон)
- Чат с мастером в реальном времени (Supabase Broadcast)
- Выбор мастера → статус "Мастер выбран"
- Отметить заявку как завершённую
- Оценка мастера (звёзды + комментарий) после завершения
- Жалоба на мастера из карточки заявки

**Мастер**
- Просмотр всех открытых заявок
- Отклик с ценой, сроком, комментарием (авторасчёт цены по ставке)
- Список своих откликов с индикатором непрочитанных сообщений
- Чат с клиентом в реальном времени
- Жалоба на клиента из карточки заявки

**Профиль**
- Редактирование имени, телефона, района
- Мастер устанавливает ставку отдельно по каждому виду работ
- Редирект на страницу заявок после сохранения

**Виды работ**
- Список работ в БД (включая "Другое" и "Собрать мебель")
- "Другое" — показывает дополнительное текстовое поле
- "Собрать мебель" — меняет "площадь м²" на "количество единиц"

**Уведомления**
- Email-уведомления через Supabase / Resend ✅

**Админ-панель** (`/admin`)
- Управление пользователями (список клиентов/мастеров, удаление)
- Управление видами работ (добавить / удалить без SQL)
- Управление жалобами (просмотр, удаление пользователя, отклонение жалобы)
